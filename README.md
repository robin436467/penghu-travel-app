# 澎湖帶團出遊

團體旅遊用的網頁 App（PWA），資料取自 `澎湖行程.xlsx`。風格參考「去趣 ChicTrip」：乾淨白卡、藍色主按鈕、Lucide 線條圖示，全繁體中文。

## 功能

- **總覽**：行程主視覺、團員、預算總額、每日亮點，一鍵跳到各功能。
- **行程**：第 1～5 天分頁時間軸。每個行程點可
  - 點「導航前往」直接開 Google 地圖路線
  - 更換景點、標記不參加、刪除、新增行程點
- **探索**：景點 / 美食 / 早餐 / 咖啡廳 / 雨天備案 / 名產，可依地區篩選與搜尋。
  - 點進景點看介紹、評分、營業時間、地址 → 導航或「加入行程」。
- **記帳**：
  - 花費明細：新增花費（誰付的、分攤給誰、依大人 1 / 小孩 0.5 權重）
  - 結算：每人應收／應付，與最少筆數的還款建議
  - 預算估算：Excel 原始預算表（唯讀）

資料存在瀏覽器 `localStorage`，重開不會掉。每位團員各自一份（單機版）。

## 開發 / 執行

```bash
npm install
npm run dev      # 本機開發 http://localhost:5173
npm run build    # 打包到 dist/
npm run preview  # 預覽打包結果
```

手機上開啟後，瀏覽器選單選「加到主畫面」即可像 App 一樣使用。

## 之後要全團即時同步

資料層集中在 `src/store.jsx`。要做到「A 記一筆、B 立刻看到」時，把 `localStorage` 換成雲端（如 Supabase）即可，畫面與邏輯不用大改。
